**Orbit Harvest** — a tiny orbital arcade. Pilot a harvester ship around a living planet, catch glowing star-seeds to fill the hold, and dodge the asteroids tumbling through the rings. Every seed builds your combo; every hit costs hull and resets it. Reach 1,000 points for a bountiful harvest, or lose all three hearts and the harvest is lost. Levels raise the pace and the rock count, a dash gets you out of trouble, and WebAudio bleeps mark every catch, hit and level-up. Plain Canvas 2D, no libraries, no network — just static files.

## Run it

```sh
cd game && python3 -m http.server 8000
# open http://localhost:8000 in a desktop browser
```

Controls: ← → steer orbit, ↑ ↓ change ring, SPACE dash, hold the mouse to steer toward the pointer, ENTER start, R restart, M mute.
